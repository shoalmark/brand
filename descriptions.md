# Describing shoalmark

Ready to paste. Each is true of what a reader can open today:
- the shoalmark workbench, which runs today;
- ⌜skills⌟, which is ready to use;
- ⌜hail/1⌟, a first edition whose tools come next.

The planned blocks are named only as planned.

## One line (72 characters)

> Building blocks for builders who run agents; the final word stays yours.

## Short (51 words)

> shoalmark.tools is a family of building blocks for builders who run agents. Each stands alone in your own repository
> and composes with the others when you choose. The shoalmark workbench runs today; ⌜skills⌟ is ready to use and
> ⌜hail/1⌟ to read. The agents do the work; the final word stays yours.

## Long (102 words)

> shoalmark.tools is a family of building blocks for builders who run agents. Each stands alone in your own repository
> and composes with the others, when you choose, through plain files in git. The shoalmark workbench runs today: work
> items in Markdown, your answers as your own commits, and a board that puts what waits for you first. ⌜skills⌟ holds
> procedures agents run to find drift and prune stale prose. ⌜hail/1⌟, the protocol by which agent seats message each
> other, is a first edition; its tools come next. ⌜chart/1⌟ and ⌜tracker/1⌟ are planned. The agents do the work; the
> final word stays yours.

**Where the corner marks can't be set,** write `skills`, `hail/1`, `chart/1` and `tracker/1`.
